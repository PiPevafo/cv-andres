Team project in the IBM Quantum Qiskit Advocate Mentorship Program (Nov 2025 – Feb 2026). Starting from historical asset data (expected returns $\mu$ and a Ledoit–Wolf-shrunk covariance $\Sigma$), the mean–variance problem $\max_x\, \mu^T x - \lambda\, x^T \Sigma x$ with a budget constraint is cast as a QUBO and solved with QAOA using an XY-mixer that preserves the number of selected assets.

The workflow benchmarks QAOA against brute force and CVXPY, sweeps the risk-aversion parameter $\lambda$, runs GPU simulations, and compares ideal, noisy (fake backend) and real IBM Quantum hardware executions.
